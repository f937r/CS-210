**Banking Application**

- This application is used to calculate the yearly balance using input from the user. The user will enter the initial deposit, any
  monthly deposit, the interest rate as a double (i.e. 1.5 for 1.5%) and the number of years to allow the investment to grow. The
  program will return the year end balance and interest earned with both no deposit and the user provided monthly deposit so the
  values can be compared.
