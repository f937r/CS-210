**Summarize the project and what problem it was solving.**

- This application is used to calculate the yearly balance using input from the user. The user will enter the initial deposit, any
  monthly deposit, the interest rate as a double (i.e. 1.5 for 1.5%) and the number of years to allow the investment to grow. The
  program will return the year end balance and interest earned with both no deposit and the user provided monthly deposit so the
  values can be compared.

**How did you make this program maintainable, readable, and adaptable?**

- I used best practices by creating separate modules for each function so that the code can be maintained independent of each other.
  By doing this, it is much easier to locate specific parts of the program to make any future enhancements and used naming conventions
  that make identifying the separate functions easier. By separating each part, it makes it much easier to also compile each piece separately,
  so if I, or another programmer, makes a change to a function, it can be compiled on its own to catch any syntax or compilation errors.
  By also using in-line comments, it makes it easier for an outside person to understand what the program is doing at each step.
